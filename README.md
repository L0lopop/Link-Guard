# Link Guard

Плагин для **exteraGram** и **AyuGram**: разбирает ссылку до того, как вы по ней перейдёте, и вычищает трекеры.

Ничего не отправляет наружу — весь анализ выполняется на устройстве.

## Что делает

**Проверяет ссылку перед открытием.** Если всё в порядке — молча пропускает. Если нет — показывает разбор и даёт решить самому.

| Приём | Пример |
|---|---|
| Подмена домена через `@` | `sberbank.ru@phish.top/login` ведёт на `phish.top` |
| Опечатка в известном домене | `sberbamk.ru` вместо `sberbank.ru` |
| Кириллица под латиницу | `sbеrbank.ru` с русской «е» |
| Punycode | `xn--80ak6aa92e.com` показывается в читаемом виде |
| Бренд в поддомене | `gosuslugi.ru.verify-account.cyou` |
| Опасные схемы | `javascript:`, `data:`, `file:`, `intent:` |
| Установочные файлы | ссылка на `.apk`, `.exe`, `.scr` |
| Прочее | IP вместо домена, нестандартный порт, зоны `.top/.zip/.cyou`, слова-приманки |

**Чистит трекеры.** Более 30 параметров точным списком (`fbclid`, `gclid`, `yclid`, `msclkid`, `mc_cid` и другие) плюс префиксы `utm_*`, `pk_*`, `hsa_*`. Работает и при переходе, и в ваших исходящих сообщениях. Агрессивный режим дополнительно снимает `ref`, `si`, `spm`, `from` — по умолчанию выключен, потому что редкие сайты на них завязаны.

**Разворачивает короткие ссылки.** `bit.ly`, `clck.ru`, `vk.cc` и ещё два десятка сервисов: показывает конечный адрес и число редиректов, конечный адрес тоже проходит полную проверку.

**Два пункта в меню сообщения** — «Проверить ссылки» (разбирает все ссылки разом, включая спрятанные под текстом) и «Копировать без трекеров».

## Установка

1. Скачайте [`src/link_guard.plugin`](src/link_guard.plugin).
2. Отправьте файл самому себе в «Избранное».
3. Тапните по нему в чате → «Установить» → «Включить после установки».

Требуется клиент версии 11.9.1 или новее с включённым движком плагинов.

## Что уходит в сеть

Проверка ссылок целиком локальная, списки зашиты в файл. Наружу плагин обращается ровно в двух случаях, и оба отключаются тумблером в настройках:

- **разворачивание короткой ссылки** — HEAD-запрос по самой ссылке, чтобы узнать конечный адрес;
- **проверка обновлений** — раз в сутки читает `update.json` из этого репозитория.

Ни содержимое переписки, ни ваши ссылки никуда не передаются.

## Разработка

```bash
python tests/test_link_guard.py
```

Тесты подменяют Android-модули заглушками и прогоняют логику целиком: разбор ссылок, перехват перехода, чистку исходящих, проверку обновлений и работу на урезанном SDK. Отдельно контролируется точность — выборка нормальных ссылок должна проходить без единого предупреждения.
