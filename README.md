# Link Guard

Плагин для **exteraGram** и **AyuGram**: разбирает ссылку до того, как вы по ней перейдёте, и вычищает трекеры.

Разбор ссылок выполняется на устройстве: списки зашиты в сам плагин.

## Что делает

**Проверяет ссылку перед открытием.** Если всё в порядке — молча пропускает. Если нет — показывает разбор и даёт решить самому.

| Приём | Пример |
|---|---|
| Подмена домена через `@` | `sberbank.ru@phish.top/login` ведёт на `phish.top` |
| Опечатка в известном домене | `sberbamk.ru` вместо `sberbank.ru` |
| Кириллица под латиницу | `sbеrbank.ru` с русской «е» |
| Punycode | `xn--80ak6aa92e.com` показывается в читаемом виде |
| Бренд в поддомене | `gosuslugi.ru.verify-account.cyou` |
| Опасные схемы | `javascript:`, `data:`, `file:`, `intent:` |
| Установочные файлы | ссылка на `.apk`, `.exe`, `.scr` |
| Прочее | IP вместо домена, нестандартный порт, зоны `.top/.zip/.cyou`, слова-приманки |

**Чистит трекеры.** Более 30 параметров точным списком (`fbclid`, `gclid`, `yclid`, `msclkid`, `mc_cid` и другие) плюс префиксы `utm_*`, `pk_*`, `hsa_*`. Работает и при переходе, и в ваших исходящих сообщениях. Агрессивный режим дополнительно снимает `ref`, `si`, `spm`, `from` — по умолчанию выключен, потому что редкие сайты на них завязаны.

**Разворачивает короткие ссылки.** `bit.ly`, `clck.ru`, `vk.cc` и ещё два десятка сервисов: показывает конечный адрес и число редиректов, конечный адрес тоже проходит полную проверку.

**Ловит подмену подписи.** Если в сообщении ссылка подписана как `sberbank.ru`, а ведёт на другой домен, плагин скажет об этом прямо в разборе.

**Два пункта в меню сообщения** — «Проверить ссылки» (разбирает все ссылки разом, включая спрятанные под текстом) и «Копировать без трекеров».

**Знает, откуда ссылка.** Из канала или от незнакомца — проверяет строже, от вашего контакта или из «Избранного» — мягче. Адрес в домашней сети не считается угрозой.

**Умеет узнавать возраст домена.** Свежая регистрация вместе с имитацией известного бренда — почти всегда мошенничество. Выключено по умолчанию: запрос уходит на сторонний сервис rdap.org.

**Знает мошеннические сайты в лицо.** База из семи публичных списков — больше 2,8 млн адресов — собирается в этом репозитории каждую ночь и приезжает готовым файлом. Проверка идёт на устройстве: ни один адрес наружу не уходит. Доступны два объёма: ядро на 1,4 МБ с сайтами, которые притворяются известными сервисами, и полная база на 8,3 МБ.

Известные посещаемые сайты в базу не попадают: списки регулярно ошибаются и вносят туда github.com или dropbox.com. Площадки, раздающие адреса всем желающим, распознаются отдельно — мошеннический сайт на них помечается поимённо, а сама площадка нет.

**Списки пополняются без обновления плагина.** Новые бренды, метки слежения и мошеннические зоны приезжают из файла `rules.json` в этом репозитории. Правила умеют только добавлять проверки — отключить защиту через них нельзя.

## Настройки

Показывать разбор можно при любой находке анализатора или для каждой ссылки подряд. Доверенные домены живут отдельным списком: добавляются полем с кнопкой, удаляются долгим нажатием. В диалоге опасной ссылки главная кнопка — «Отмена», чтобы случайный тап не открывал фишинг.

Статистика показывает, сколько меток вырезано и сколько предупреждений показано; счётчики сбрасываются нажатием.

## Установка

1. Скачайте [`src/link_guard.plugin`](src/link_guard.plugin).
2. Отправьте файл самому себе в «Избранное».
3. Тапните по нему в чате → «Установить» → «Включить после установки».

Требуется клиент версии 11.9.1 или новее с включённым движком плагинов.

## Что уходит в сеть

Разбор ссылок целиком локальный. Наружу плагин обращается в пяти случаях, и каждый отключается тумблером в настройках:

- **разворачивание короткой ссылки** — HEAD-запрос по самой ссылке, чтобы узнать конечный адрес;
- **проверка обновлений** — раз в сутки читает `update.json` из этого репозитория; при согласии скачивает файл и открывает штатный экран установки, проверив, что это действительно Link Guard;
- **списки правил** — раз в сутки читает `rules.json` оттуда же;
- **база мошеннических сайтов** — раз в сутки скачивает готовый файл из релиза этого репозитория; какие адреса вы проверяете, при этом не сообщается никому;
- **возраст домена** — только если вы включите этот тумблер: адрес проверяемого домена уходит на rdap.org.

Ни содержимое переписки, ни ваши ссылки никуда не передаются.

## Разработка

```bash
python tests/test_link_guard.py
python scripts/build_db.py && python tests/test_db_format.py
```

Первый набор подменяет Android-модули заглушками и прогоняет логику целиком: разбор ссылок, перехват перехода, чистку исходящих, проверку обновлений, работу с базой и совместимость с урезанным SDK. Отдельно контролируется точность — выборка нормальных ссылок должна проходить без единого предупреждения.

Второй собирает настоящую базу из публичных списков и проверяет её на реальных данных: что формат читается, что тысяча посещаемых сайтов не вызывает тревог и что площадки общего хостинга не блокируются целиком.

Источники базы: [HaGeZi](https://github.com/hagezi/dns-blocklists), [Phishing Army](https://phishing.army), [Phishing.Database](https://github.com/Phishing-Database/Phishing.Database), [CERT.PL](https://cert.pl), [The Block List Project](https://github.com/blocklistproject/Lists), [malware-filter](https://gitlab.com/malware-filter), [URLhaus](https://urlhaus.abuse.ch). Список посещаемых сайтов — [Tranco](https://tranco-list.eu), разделение доменов — [Public Suffix List](https://publicsuffix.org).
